# 01 — 环境与项目定位

> 项目路径：`E:\AI知识平台\knowflow-ai`（或仓库根目录 `knowflow-ai/`）

## 当前状态

```text
生产可演示版 / 准生产 Beta 版
```

## 已完成能力

- 用户注册、登录、JWT 鉴权
- 知识库 CRUD、分页列表 API（`{ items, total, skip, limit }`）
- 文档上传、解析、切片、向量化（Celery / background）
- ChromaDB 向量写入与检索
- Hybrid Search、Reranker、Embedding 抽象
- Redis RAG cache（KB 级失效，Redis SCAN，非 KEYS）
- SSE 流式 RAG 问答与 references
- DocumentPreviewPanel、引用跳转
- 中英文 i18n（Login / Dashboard / KB 详情）
- Prometheus `GET /api/metrics`
- K8s 基础清单（`deploy/k8s/`）
- Playwright 自动拉起前端 dev server
