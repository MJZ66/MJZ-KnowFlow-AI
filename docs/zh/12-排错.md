# 12 — 常见问题排查

## 1. docker compose 报 no configuration file

**原因：** 当前目录不是项目根目录。

**解决：**

```powershell
cd E:\AI知识平台\knowflow-ai
```

## 2. 前端 JSON 解析失败

**原因：** `zh-CN.json` / `en-US.json` 字符串内双引号未转义。

**验证：**

```powershell
cd frontend
node -e "JSON.parse(require('fs').readFileSync('./src/i18n/locales/zh-CN.json','utf8')); console.log('OK')"
node -e "JSON.parse(require('fs').readFileSync('./src/i18n/locales/en-US.json','utf8')); console.log('OK')"
```

## 3. Playwright 找不到浏览器

```powershell
cd frontend
npx playwright install chromium
```

## 4. Playwright 连接被拒绝（5173）

**原因：** 测试用了错误 baseURL；Vite 默认端口为 **3000**。

**解决：** 不设置 `PLAYWRIGHT_BASE_URL`，或设为 `http://localhost:3000`；E2E 使用相对路径 `/register`。

## 5. RAG 召回旧失败文档

**检查：**

- `_filter_valid_chunks()` 仅保留 `COMPLETED` 文档
- references 去重逻辑
- 上传后文档是否真正 `COMPLETED`

## 6. Chroma 维度冲突

**原因：** 同一 collection 混用 384 维（hash）与 1024 维（BGE）。

**解决：**

- 新建知识库
- 或重建索引 / 清理旧 collection
- API 返回 `VECTOR_DIMENSION_MISMATCH`

## 7. Celery 任务卡住

```powershell
docker compose logs celery-worker --tail 200
docker compose logs backend --tail 100
```

确认：

```text
TASK_BACKEND=celery
REDIS_URL 正确
backend 与 celery-worker 共享 uploads 卷
```

## 8. 后端 ImportError / 无法启动

查看：

```powershell
docker compose logs backend --tail 50
```

常见：`main.py` 错误 import、迁移失败。

## 9. /api/metrics 404

```env
METRICS_ENABLED=true
```
