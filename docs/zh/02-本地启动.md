# 02 — 本地开发启动

## 1. 后端与基础设施

```powershell
cd E:\AI知识平台\knowflow-ai

docker compose up -d postgres redis chromadb
docker compose up --build -d backend celery-worker
```

健康检查：

```powershell
curl http://localhost:8000/api/health
curl http://localhost:8000/api/health/live
curl http://localhost:8000/api/health/ready
curl http://localhost:8000/api/metrics
```

预期：

- `/api/health` → `status=ok`
- `/api/metrics` → Prometheus 文本格式（需 `METRICS_ENABLED=true`）

## 2. 前端

```powershell
cd E:\AI知识平台\knowflow-ai\frontend

npm install
npm run dev
```

默认访问：**http://localhost:3000**（见 `vite.config.ts`）

Vite 已将 `/api` 代理到 `http://localhost:8000`。

若端口被占用（如 3001），Playwright 可覆盖：

```powershell
$env:PLAYWRIGHT_BASE_URL="http://localhost:3001"
```

## 3. 一键浏览器 E2E

```powershell
cd E:\AI知识平台\knowflow-ai\frontend
npm run e2e
```

说明：

- Playwright 自动执行 `npm run dev -- --host 0.0.0.0`
- `reuseExistingServer: true`：已有 dev 则复用
- 默认 `baseURL`：`http://localhost:3000`
- 可用 `PLAYWRIGHT_BASE_URL` 覆盖

首次运行需安装浏览器：

```powershell
npx playwright install chromium
```
