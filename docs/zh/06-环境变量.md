# 06 — 环境变量

模板文件（勿提交真实 `.env` 与密钥）：

| 文件 | 用途 |
|------|------|
| `.env.example` | 默认开发 |
| `.env.development.example` | 开发命名模板 |
| `.env.staging.example` | 预发 |
| `.env.production.example` | 生产 |

## 1. 基础环境

```env
APP_ENV=development
SECRET_KEY=change-me-to-a-long-random-secret
DATABASE_URL=postgresql+asyncpg://knowflow:knowflow_secret@postgres:5432/knowflow
REDIS_URL=redis://redis:6379/0
CHROMA_HOST=chromadb
CHROMA_PORT=8000
ALLOWED_ORIGINS=http://localhost:3000,http://localhost:5173
```

生产：`APP_ENV=production` 时 `SECRET_KEY` 必须非默认且长度 ≥ 32，否则进程拒绝启动。

## 2. 任务队列

```env
TASK_BACKEND=celery
```

| 值 | 说明 |
|----|------|
| `celery` | 生产推荐，独立 worker |
| `background` | 单机调试，FastAPI BackgroundTasks |

## 3. RAG 缓存

```env
RAG_CACHE_ENABLED=true
RAG_CACHE_TTL_SECONDS=300
```

- Cache key：`rag:{kb_id}:{user_id}:{sha256(query+lang)}`
- 文档完成 / 删除、知识库删除时触发 KB 级 cache 失效
- 使用 Redis **SCAN**，不使用 KEYS

## 4. Embedding / 向量

当前稳定默认：

```env
VECTOR_PROVIDER=chroma_hash
EMBEDDING_PROVIDER=hash
EMBEDDING_DIM=384
```

可选 local_bge：

```env
VECTOR_PROVIDER=chroma
EMBEDDING_PROVIDER=local_bge
EMBEDDING_MODEL=BAAI/bge-m3
EMBEDDING_DIM=1024
```

注意：

- 未安装 `sentence-transformers` 时应 fallback hash
- 切换 1024 维后建议**新建知识库**
- 维度冲突返回错误码 `VECTOR_DIMENSION_MISMATCH`

## 5. Hybrid Search

```env
HYBRID_SEARCH_ENABLED=false
HYBRID_VECTOR_WEIGHT=0.7
HYBRID_KEYWORD_WEIGHT=0.3
KEYWORD_TOP_K=20
VECTOR_TOP_K=20
```

## 6. Reranker

```env
RERANKER_ENABLED=false
RERANKER_PROVIDER=noop
RERANKER_MODEL=bge-reranker-v2-m3
RERANKER_TOP_N=5
RETRIEVAL_OVERSAMPLE=4
```

## 7. Metrics

```env
METRICS_ENABLED=true
```

关闭时 `GET /api/metrics` 返回 **404**。

## 8. 上传安全

```env
MAX_UPLOAD_SIZE_MB=30
ALLOWED_FILE_EXTENSIONS=pdf,docx,md,txt,xlsx,xls,png,jpg,jpeg,webp,gif,bmp
```
