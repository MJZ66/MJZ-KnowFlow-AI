# 13 — 团队开发流程

## 每次改动前

```powershell
cd E:\AI知识平台\knowflow-ai
git status
```

确认在正确分支、了解未提交变更。

## 每次改动后（固定验收）

```powershell
cd E:\AI知识平台\knowflow-ai
docker compose up --build -d backend celery-worker

cd backend
python scripts\e2e_acceptance.py
docker compose exec backend pytest tests/ -v

cd ..\frontend
npm run build
npm run test:run
npm run e2e
```

合并到 `main` 前：确认 GitHub Actions CI 全绿（`.github/workflows/ci.yml`）。

可选（检索相关改动）：

```powershell
docker compose exec backend python scripts/retrieval_quality_check.py
```

## 通过标准

| 检查项 | 基线 |
|--------|------|
| `e2e_acceptance.py` | 13/13 |
| `pytest` | 63 passed, 2 skipped |
| `npm run build` | pass |
| `npm run test:run` | 19 passed |
| `npm run e2e` | 4 passed |

## Commit 消息建议

```text
feat(rag): add hybrid retrieval metrics
fix(frontend): handle preview drawer close state
test(e2e): cover reference preview on kb detail page
docs(zh): split deployment guide into chapters
chore(deploy): update k8s secret example
```

格式：`type(scope): 简短说明`（英文或中文均可，团队统一即可）。

## 提交前禁止

- 真实 `.env`、API Key、数据库密码
- `node_modules`、`dist`、大文件 uploads
- 未跑通的验收（除非 WIP 草稿 PR 并标注）
