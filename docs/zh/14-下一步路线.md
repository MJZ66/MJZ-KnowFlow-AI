# 14 — 下一阶段路线

## 优先级 1：生产部署演练

```text
使用 .env.production.example 填真实配置
docker compose --profile production up --build -d
验证 Nginx / Ingress / TLS
验证 Prometheus scrape
验证 SECRET_KEY 生产校验
验证 CORS 仅正式域名
GitHub Actions CI 首次跑通并设为合并门禁
```

## 优先级 2：真实 Embedding

```text
启用 EMBEDDING_PROVIDER=local_bge
新建知识库（避免维度冲突）
上传标准中文测试文档
运行 retrieval_quality_check.py
对比 hash vs BGE 召回 quality
记录 raw/valid/reranked 统计
```

## 优先级 3：体验增强

```text
文档搜索与筛选
Admin 监控图表面板
聊天历史搜索
图片 OCR（提升图片 RAG）
DOCX / Excel 样式化预览
Playwright 覆盖多格式预览
```

> 已完成：多文件上传、上传进度条、PDF/图片原文件预览、Excel/Word 文本预览

## 优先级 4：运维增强

```text
Grafana Dashboard（对接 /api/metrics）
日志集中化（Loki / ELK）
数据库与 uploads 备份恢复脚本
Celery Flower 任务监控
异常告警（失败率、队列积压）
HPA / VPA（K8s）
```
