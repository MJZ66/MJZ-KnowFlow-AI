# 17 — 服务器上线前检查清单

在运行 `.\deploy_all.ps1` 或 `bash deploy/deploy.sh` 之前，逐项确认。

---

## 1. 环境与密钥

| 项 | 要求 |
|----|------|
| `.env` | 已从 `.env.example` 或 `.env.production.example` 复制，**未提交 Git** |
| `SECRET_KEY` | 生产随机字符串 ≥ 32 字符，非 `change-me` |
| `APP_ENV` | 生产设为 `production`（uvicorn 4 workers，无 reload） |
| `LLM_API_KEY` | 已填写且可用 |
| `ALLOWED_ORIGINS` | 含真实前端域名（HTTPS），逗号分隔 |
| `POSTGRES_PASSWORD` | 非默认弱密码（公网暴露时必改） |

---

## 2. 永久管理员（MJZ）

| 项 | 说明 |
|----|------|
| `PROMOTE_USER_ON_START` | `true`（每次 backend 启动幂等提升） |
| `PROMOTE_USER_EMAIL` | `2429448372@qq.com` |
| `PROMOTE_USER_USERNAME` | `MJZ` |
| `PROMOTE_USER_PASSWORD` | **仅**在服务器 `.env` 可选设置；勿写入仓库 |
| 验证 | 部署后 `docker compose logs backend \| grep Promoted` |

---

## 3. Docker 全栈

```powershell
cd knowflow-ai
.\deploy_all.ps1
# 或生产统一入口（含 nginx）:
.\deploy_all.ps1 -Production
```

Linux:

```bash
chmod +x deploy/deploy.sh
./deploy/deploy.sh
# ./deploy/deploy.sh --production
```

**必须运行的容器：**

- `knowflow-postgres`、`knowflow-redis`、`knowflow-chromadb`
- `knowflow-backend`、`knowflow-celery-worker`
- `knowflow-frontend`（3000→80）
- 可选：`knowflow-nginx`（`--profile production`）

**数据卷（勿删）：** `knowflow_postgres_data`、`knowflow_uploads_data`、`knowflow_chroma_data`

---

## 4. 验收基线

| 命令 | 预期 |
|------|------|
| `curl http://localhost:8000/api/health` | `"status":"ok"` |
| `python backend/scripts/e2e_acceptance.py` | 13/13 |
| `docker compose exec backend pytest tests/ -q` | 全部通过 |
| `cd frontend && npm run build` | 无 TS 错误 |
| `cd frontend && npm run test:run` | 全部通过 |

---

## 5. 生产加固

- [ ] HTTPS（Nginx / Caddy / 云 LB）终止 TLS
- [ ] 仅暴露 80/443，数据库/Redis **不**映射公网（改 compose 去掉 ports 或防火墙）
- [ ] `METRICS_ENABLED=true` 时限制 `/api/metrics` 访问
- [ ] 定期备份 Postgres 卷
- [ ] `TASK_BACKEND=celery` 且 `celery-worker` 健康
- [ ] 上传目录 `knowflow_uploads_data` 与 worker 共用
- [ ] 首次上线后修改默认 `ADMIN_PASSWORD` / 轮换 MJZ 密码

---

## 6. 前端访问

| 模式 | URL |
|------|-----|
| Docker 前端 | `http://<host>:3000` |
| Nginx 统一入口 | `http://<host>:80`（`NGINX_PORT`） |
| API | `http://<host>:8000` 或经 Nginx `/api/` |

开发调试仍可用「后端 Docker + `npm run dev`」，见 [16-最短部署清单.md](./16-最短部署清单.md)。

---

## 7. 快速排错

| 现象 | 处理 |
|------|------|
| 迁移失败 | `docker compose logs backend`，`alembic upgrade head` |
| MJZ 非管理员 | 确认 `.env` 中 `PROMOTE_USER_ON_START=true`，`docker compose up -d backend --force-recreate` |
| 文档不处理 | 检查 `celery-worker` 与 `TASK_BACKEND=celery` |
| CORS 错误 | 更新 `ALLOWED_ORIGINS` 为浏览器实际 Origin |
