# 05 — 数据库检查

在仓库根目录执行：

## documents

```powershell
docker compose exec postgres psql -U knowflow -d knowflow -P pager=off -c "select id, original_filename, status, error_message from documents order by id desc limit 10;"
```

## background_tasks

```powershell
docker compose exec postgres psql -U knowflow -d knowflow -P pager=off -c "select id, task_type, status, related_document_id, progress, error_message from background_tasks order by id desc limit 10;"
```

## document_chunks

```powershell
docker compose exec postgres psql -U knowflow -d knowflow -P pager=off -c "select id, document_id, chunk_index, vector_provider, external_vector_id from document_chunks order by id desc limit 20;"
```

## 预期结果

| 场景 | 预期 |
|------|------|
| 正常上传文档 | `documents.status = COMPLETED` |
| 空/无效文档 | `documents.status = FAILED`，有 `error_message` |
| 处理完成 | `background_tasks.status = COMPLETED`，`progress = 100` |
| 向量化成功 | `document_chunks.external_vector_id` 非空 |
| RAG 引用 | FAILED 文档 chunk 不进入 references |
