# 04 — 前端验收

```powershell
cd E:\AI知识平台\knowflow-ai\frontend

npm run build
npm run test:run
npm run e2e
```

## 当前基线

| 命令 | 预期 |
|------|------|
| `npm run build` | TypeScript + Vite 生产构建通过 |
| `npm run test:run` | Vitest **12 passed** |
| `npm run e2e` | Playwright **2 passed**（自动拉起 dev server） |

## E2E 覆盖范围

1. 注册 → 创建 KB → 上传 → RAG 问答 → 引用预览 → KB 页语言切换持久化
2. Dashboard 知识库分页控件

## 前置条件

- Docker 中 `backend`、`celery-worker` 已启动
- 首次 E2E：`npx playwright install chromium`
