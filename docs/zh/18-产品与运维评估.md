## 2. 产品评估

### 2.1 核心价值（已交付）

```text
上传 → 解析 → 切片 → 向量化 → RAG 问答 → 引用溯源 → 文档预览
```

| 模块 | 状态 | 备注 |
|------|------|------|
| 用户与权限 | ✅ | JWT + KB 成员角色 + Admin |
| 知识库管理 | ✅ | CRUD、分页、公开发布审批 |
| 文档处理 | ✅ | Celery 异步，状态轮询 |
| 多格式支持 | ✅ | PDF/DOCX/XLSX/XLS/MD/TXT/图片 |
| 预览 | ✅ | 文本分块 + PDF iframe + 图片原图 |
| 问答 | ✅ | SSE 流式 + ReferencePanel |
| 国际化 | ✅ | 中英文 |
| 管理后台 | ✅ | 用户/KB/任务基础管理 |

### 2.2 体验差距（按优先级）

| 优先级 | 项 | 影响 |
|--------|-----|------|
| P1 | 未配置 `LLM_API_KEY` 时问答失败 | 新用户 onboarding 体验差，需引导页 |
| P1 | Hash embedding 检索质量有限 | 生产场景答案相关性不足 |
| P2 | DOCX/Excel 仅文本预览 | 复杂排版信息丢失 |
| P2 | 图片无 OCR | 扫描件/截图无法检索文字 |
| P3 | 成员管理 UI 较弱 | 团队协作场景 |
| P3 | Admin 缺图表 | 运营观测不便 |

### 2.3 产品路线图建议

**短期（1–2 周）**

- 配置向导：检测 LLM Key / 文档处理状态并给出明确提示
- 图片 OCR（可选 tesseract）提升图片 RAG 质量
- Playwright 覆盖「上传 → 预览」新格式

**中期（1 月）**

- 生产默认 `local_bge` embedding + Hybrid 调参
- Grafana + Prometheus 告警规则
- Postgres / uploads 自动备份脚本

**长期**

- 团队协作（成员 UI、审计日志）
- 多租户 / 配额
- 检索质量 A/B 与反馈闭环

## 4. 运维评估

### 4.1 部署架构

```text
[用户] → frontend:3000 / nginx:80
           ↓ /api
        backend:8000 ←→ postgres / redis / chromadb
           ↓
        celery-worker（文档处理）
```

| 项 | 状态 |
|----|------|
| Docker Compose 开发/生产 profile | ✅ |
| K8s 清单草案 | ✅ |
| 一键脚本 deploy_all.ps1 / deploy.sh | ✅ |
| GitHub Actions CI | ✅ `.github/workflows/ci.yml` |
| 健康检查 live/ready | ✅ |
| Prometheus metrics | ✅（需限制外网访问） |

### 4.2 安全清单

| 项 | 开发 | 生产必须 |
|----|------|----------|
| `SECRET_KEY` ≥ 32 字符 | 可默认 | **必须** |
| `LLM_API_KEY` | 占位可启动 | **必须有效** |
| `ALLOWED_ORIGINS` | localhost | 真实域名 |
| `PROMOTE_USER_*` | 便于调试 | 密码仅放服务器 `.env` |
| DB/Redis 公网暴露 | compose 默认映射 | 防火墙/去掉 ports |
| `/api/metrics` | 开放 | IP 白名单或内网 |

### 4.3 运维差距

| 项 | 现状 | 建议 |
|----|------|------|
| 日志集中 | 容器 stdout | Loki/ELK 或云日志 |
| 告警 | 无 | Prometheus → Alertmanager |
| 备份 | 文档提及 | 定时 pg_dump + uploads 卷快照 |
| Celery 监控 | 无 Flower | 可选部署 Flower |
| 灾难恢复 | 未演练 | 季度恢复演练 |
