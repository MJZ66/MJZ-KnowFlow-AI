# 10 — 生产安全检查

## 1. SECRET_KEY

生产环境：

```env
APP_ENV=production
SECRET_KEY=<随机字符串，至少 32 字符>
```

要求：

- 非默认值 `change-me-to-a-random-secret-key-at-least-32-chars`
- 长度 ≥ 32
- 否则应用启动失败（`validate_production_settings`）

开发环境可使用默认值，启动时仅警告。

## 2. CORS

生产：

```env
ALLOWED_ORIGINS=https://your-domain.com
```

- 使用逗号分隔多个域名
- **不要**使用 `*` 或保留 localhost（除非内网调试）

## 3. 文件上传

必须启用（代码已实现）：

| 措施 | 说明 |
|------|------|
| 扩展名白名单 | pdf, docx, md, txt |
| MIME / magic 检查 | 防止伪装类型 |
| 文件名清洗 | 去路径、特殊字符、长度限制 |
| 大小限制 | `MAX_UPLOAD_SIZE_MB`（默认 30） |

禁止示例：

```text
.exe / .bat / .sh
路径穿越 ../
超大文件（> 限制）
```

## 4. 密钥与敏感数据

**禁止提交到 Git：**

```text
.env（真实配置）
API Key / LLM Key
数据库密码
模型权重目录
uploads 用户文件
node_modules
```

使用：

- `.env.example` 等模板
- K8s `secret.yaml`（本地 apply，不入库）
- CI/CD 密钥注入

## 5. 网络暴露

生产环境：

- 仅暴露 Nginx / Ingress（443）
- PostgreSQL、Redis、ChromaDB 仅集群内网或 Docker 内网
