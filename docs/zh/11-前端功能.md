# 11 — 前端功能

## 已有页面 / 路由

| 路由 | 说明 |
|------|------|
| `/login` | 登录 |
| `/register` | 注册 |
| `/dashboard` | 知识库列表（分页） |
| `/kbs/:kbId` | 知识库详情：文档管理 + 问答（双栏） |
| `/admin` | 管理面板（需 admin 权限） |

> 注：问答主流程在 `/kbs/:kbId` 内完成；若存在独立 chat 路由以 `routes/index.tsx` 为准。

## 已有能力

```text
中英文切换（LangSwitcher）
localStorage 语言持久化（knowflow_lang）
Dashboard 知识库分页（items/total/skip/limit）
KB 详情页语言切换（kb-detail-lang-switcher）
双栏布局：文档区 + 会话问答区
文档上传（拖拽 / 选择，多文件批量）
上传进度条（XHR onprogress）
支持 PDF / DOCX / XLSX / XLS / MD / TXT / 图片
文档状态轮询（COMPLETED / FAILED，静默刷新防列表抖动）
上传后一键预览（Eye 按钮 + Toast）
DocumentPreviewPanel：文本分块 / PDF iframe / 图片原图
SSE 流式回答
Markdown 渲染
ReferencePanel 引用列表
引用点击 → 定位 chunk 高亮
Playwright e2e 自动启动 dev server（desktop + mobile）
Vitest 组件测试（19）
```

## 组件与 testId（E2E）

| testId | 位置 |
|--------|------|
| `kb-create-open` | Dashboard 创建 KB |
| `kb-pagination` | Dashboard 分页 |
| `chat-new-session` | 新建会话 |
| `reference-card-0` | 引用卡片 |
| `document-preview-panel` | 预览抽屉 |
| `preview-close` | 关闭预览 |
| `preview-image` / `preview-pdf` | 图片 / PDF 原文件预览 |
| `kb-detail-lang-switcher` | KB 详情语言切换 |
| `lang-switcher` | 登录/注册/Dashboard 语言切换 |
